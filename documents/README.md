# Restaurant Rush — UML Documentation

This folder contains the UML diagrams for the **SC2002 Restaurant Rush Group Project**, documenting the system's design and development across Stages 1, 2, and 3.

## Class Diagrams

### Stage 1 — Class Diagram
Illustrates the initial system architecture, including the core classes, attributes, methods, and relationships implemented in Stage 1.

### Stage 2 — Class Diagram
Documents the updated system architecture following Stage 2 development, highlighting newly introduced classes, functionality, and changes to existing relationships.

### Stage 3 — Class Diagram
Presents the final system architecture, incorporating Stage 3 features such as Host seating, ComboMeal, and HappyHourPolicy, alongside the existing system components.

## Sequence Diagram

### Stage 3 — Sequence Diagram
Illustrates a VIP customer's gameplay journey, including arrival, Host seating, Happy Hour activation, ordering, food preparation, serving, eating, payment, and the end-of-game result check.

## File Format

All diagrams are provided in **PDF format** for easy viewing and inclusion in the final project report.

## Purpose

These diagrams document the evolution of the Restaurant Rush system, illustrating its object-oriented design, class relationships, and interactions throughout the three development stages.
